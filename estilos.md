# Guía Visual de Textos (Edición Symbionte)

Text Regular - **Bold** - *Italic* - <ins>Underline</ins> - ~~Strike (Tachado por medio)~~ - <mark>Highlight</mark> - `Type`

---

### Lista rápida para copiar y editar:

* Normal: Escribe el texto tal cual sin símbolos.
* **Negrita:** Pon `**dos asteriscos**` a cada lado.
* *Cursiva:* Pon `*un asterisco*` a cada lado.
* ~~Tachado por medio:~~ Pon `~~dos virgulillas~~` a cada lado.
* <ins>Subrayado abajo:</ins> Usa `<ins>tu texto</ins>`.
* <mark>Resaltado con fondo:</mark> Usa `<mark>tu texto</mark>`.
* `Caja de código:` Pon `` `acento grave` `` a cada lado.
